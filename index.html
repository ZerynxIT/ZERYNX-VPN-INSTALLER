نصب ZERYNX VPN روی حساب Cloudflare خودت

نصاب، آخرین سورس رسمی را دریافت می‌کند، دیتابیس D1 را می‌سازد و Worker را مستقیماً روی حساب خودت منتشر می‌کند. هیچ فایلی در ریپوی اصلی تغییر نمی‌کند.

اتصال حساب و نصب

اجرای مستقیم در مرورگر
توکن در GitHub یا LocalStorage ذخیره نمی‌شود. درخواست‌های Cloudflare از طریق Relay مدیریت‌شده ZERYNX عبور می‌کنند.
فقط یک ورودی لازم است
نام Worker به‌صورت خودکار روی zerynx-vpn تنظیم می‌شود؛ Relay ثابت ZERYNX در پشت‌صحنه استفاده می‌شود و نیازی به واردکردن URL جداگانه نیست.
برای Update از همان مرورگر و دستگاه نصب اولیه استفاده کن؛ شناسه دیتابیس قبلی حفظ می‌شود.
عملیات با موفقیت انجام شد.

روند راه‌اندازی

01
ورود و ساخت توکندر Cloudflare یک API Token بساز، آن را کپی کن و در کادر بالا قرار بده.
02
بررسی توکناعتبار توکن و حساب مقصد بررسی می‌شود.
03
دریافت سورس رسمیفایل‌های آخرین نسخه از مخزن عمومی ZERYNX دریافت می‌شوند.
04
ساخت D1 و انتشار Workerدیتابیس و فایل‌های پنل روی حساب Cloudflare خودت مستقر می‌شوند.
05
تست نهاییپاسخ Worker و اتصال واقعی D1 بررسی می‌شود.
حریم خصوصی و کنترل دسترسی
توکن را فقط در صفحه رسمی GitHub Pages وارد کن. توکن برای ارسال درخواست‌ها از مرورگر به Relay مدیریت‌شده ZERYNX فرستاده می‌شود؛ در GitHub یا LocalStorage ذخیره نمی‌شود. فقط در صورتی ادامه بده که به کد Relay اعتماد داری. پس از نصب می‌توانی توکن را لغو کنی؛ برای Update بعدی توکن تازه بساز.
